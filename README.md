# Skill-Check-game

Once again this was a project that was given to me during my internship that I could not upload before now as it was actively being worked on. After checking with both Tricky and Big Ideas I was given permission to put this code on my personal Git.

### * Because this concept has advanced and is seeking to be bought the code published is rudimentary and not the code used in the final prototype. skillCheck.java is the earliest prototype and prototypeSkillCheck.py is the earliest adaptation made and put onto an electronic prototype. *  

## Introduction:
This project idea was to make a game that would test a user's co-ordination and timing, the concept was similar to that of bop-it.
  - The user is given 4 potential targets around a circle, each a colour.
  - One of the colours will light up showing which one is the current target.
  - The user must press the corresponding button for the target light.
  - As the user hits the skill checks the speed of the checks gets faster

The skillCheck.java file allowed the companies and I to make changes to the functionality of the game without having to rebuild the prototype hardware. This included features like the difficulty choices given to the user at the beginning.

### * The final prototype featured a RPi 3B and a number of basic LEDs and buttons, wiring proved complex in the end due to the project featuring 16 LEDs in a small circle *
